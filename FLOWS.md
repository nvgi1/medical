# Main flows

## Preview entry and independent routes
- Open the deployed preview: expect the Arabic engineering hero, not the 404 page.
- On a normal standalone domain, open each of the nine routes and all three project-detail URLs directly: expect the matching page.
- An unknown standalone route shows the designed 404 page.

## Navigation and languages
- Open “القائمة” / “Explore”: expect ten page links, focus contained within the menu, Escape closes and restores focus.
- Visit every page through navigation. Switch to English: expect English content and LTR; switching back restores Arabic and RTL.
- Repeat at 375px with no horizontal overflow.

## Projects and certificates
- Select each project category: expect matching project templates or an explicit empty state.
- Open a project: expect eight editable case-study fields and media placeholders.
- Preview the certificate template, zoom, close with Escape: expect focus returned to the preview button.
- Select a certificate category with no entries: expect the explanatory empty state.

## Skills and laboratory
- Select each skills tab: expect the associated discipline panel, with no invented proficiency.
- Choose each of ten equipment entries and all three information tabs: expect corresponding content and cited references.
- Drag the model, use arrow keys, zoom, reset and pause: expect an interactive scene.
- Disable WebGL: expect a schematic alternative. Reduced motion disables ambient motion.

## Resume and contact
- Download both CVs: expect two valid, selectable-text PDF files in Arabic and English.
- Open unconfigured contact methods: expect an explanation that nothing was sent, not a simulated submission.
